# Разговорник A2–B2

Веб-приложение для изучения английских разговорных фраз уровней A2–B2 (от Pre-Intermediate до Upper-Intermediate).
Работает в браузере на телефоне и компьютере, ничего устанавливать не нужно.

Сайт: https://elmiraburkitova88-collab.github.io/Razgovornik/

## Что умеет

- Карточки в обе стороны: EN → RU и RU → EN.
- Озвучка британским голосом (Web Speech API), обычная и медленная скорость.
- Интервальное повторение: «Не знаю» — через минуту, «Не уверен» — через 10 минут,
  «Знаю» — через 1, 3, 7, 16, 35, 90 дней.
- Тесты: выбор перевода из 4 вариантов и сборка фразы из слов.
- Поиск по всем фразам и избранное.
- Светлая и тёмная тема.

Прогресс и избранное хранятся в браузере (`localStorage`), поэтому на каждом устройстве они свои.

## Как добавить фразы

Откройте `phrases.json`, найдите нужную тему по `id` и добавьте объект в массив `phrases`:

```json
{
  "en": "Could I have the bill, please?",
  "ru": "Можно счёт, пожалуйста?",
  "ex": "Could we have the bill, please? / Of course.",
  "lvl": "A2"
}
```

- `en` — фраза по-английски. Внутри одной темы не должна повторяться: по ней запоминается прогресс.
- `ru` — перевод.
- `ex` — пример. Реплики диалога разделяются символами ` / ` (пробел, косая черта, пробел).
- `lvl` — `A2`, `B1` или `B2`.

Тема без фраз показывается в списке с пометкой «Скоро».

## Запуск на компьютере

Если открыть `index.html` двойным щелчком, браузер может не дать прочитать `phrases.json`.
Тогда приложение предложит выбрать файл вручную. Либо запустите локальный сервер в папке проекта:

```
python3 -m http.server 8000
```

и откройте http://localhost:8000.
